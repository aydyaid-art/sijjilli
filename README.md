# سجلّي — دفتر الزبائن والديون

تطبيق ويب تقدمي (PWA) لتسجيل حسابات الزبائن، المبيعات، الديون، والدفعات. يعمل بالكامل بدون إنترنت، ويحفظ البيانات محلياً على الجهاز عبر IndexedDB (مع نسخة احتياطية localStorage عند عدم توفرها).

## الملفات
- `index.html` — التطبيق كاملاً (واجهة + منطق + تخزين).
- `manifest.json` — بيانات التطبيق كـ PWA (اسم، أيقونات، ألوان).
- `sw.js` — Service Worker للعمل بدون إنترنت (تخزين مؤقت للملفات).
- `icons/` — أيقونات التطبيق بأحجام مختلفة.

## رفعه على InfinityFree
1. ادخل إلى لوحة تحكم الحساب على InfinityFree.
2. من File Manager أو عبر FTP، ارفع كل محتويات مجلد `سجلي/` إلى مجلد `htdocs`.
3. تأكد أن `index.html` هو الملف الموجود مباشرة داخل `htdocs` (وليس داخل مجلد فرعي)، حتى يعمل الرابط الرئيسي للموقع مباشرة.
4. بعد الرفع، افتح رابط الموقع من الجوال — يجب أن يعمل التطبيق ويمكن "تثبيته" على الشاشة الرئيسية من قائمة المتصفح (Add to Home Screen)، وسيعمل حينها كتطبيق مستقل تقريباً.

## ملاحظة مهمة عن حفظ البيانات
البيانات تُخزَّن داخل "مساحة تخزين التطبيق" الخاصة بالمتصفح/التطبيق على الجهاز. هذا يعني:
- إغلاق وفتح التطبيق: البيانات تبقى كما هي. ✅
- مسح الكاش (Cache) من المتصفح: البيانات تبقى غالباً (مخزنة في IndexedDB وليس Cache). ✅
- مسح "بيانات التطبيق" (Clear storage / Clear data) بالكامل من إعدادات الهاتف، أو حذف التطبيق: هذا **يمسح كل شيء**، ولا يوجد أي أسلوب برمجي (لا في تطبيق ويب ولا حتى في تطبيق أندرويد أصلي عادي) يمنع نظام أندرويد من مسح مساحة تخزين التطبيق الخاصة به عند طلب المستخدم ذلك — هذا سلوك مقصود من أندرويد لحماية خصوصية المستخدم. ⚠️

**الحل العملي:** تمت إضافة ميزة "تصدير / استيراد نسخة احتياطية" (من قائمة ☰ داخل التطبيق) تُنشئ ملف JSON بكل البيانات. هذا الملف يُحفظ خارج مساحة التطبيق (في مجلد التنزيلات مثلاً)، فينجو من عملية "مسح بيانات التطبيق". في مرحلة تحويل التطبيق إلى APK يمكننا:
- إضافة نسخ احتياطي تلقائي دوري لمجلد التنزيلات العام.
- أو ربط اختياري بحساب Google Drive للنسخ الاحتياطي السحابي (هذا هو الحل الأقوى، لأنه ينجو حتى من فقدان أو استبدال الجهاز نفسه).

## الخطوات القادمة (حسب طلبك)
1. ✅ تجهيز مشروع كامل موحّد (هذه المرحلة).
2. تحويله إلى ملف APK (باستخدام أداة مثل PWA Builder أو Capacitor)، واختيار الاسم والأيقونة النهائيين.
3. نشره على متجر تطبيقات (Google Play أو متجر بديل)، مع تجهيز جميع المتطلبات (سياسة الخصوصية، شروط الاستخدام، وصف التطبيق، لقطات شاشة، إلخ).
